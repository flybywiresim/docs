# Installer Release v3.4.4

We have updated the FBW Installer to version **3.4.4**. 

This is a **minor maintenance release** over v3.4.0 that focuses on improving how the installer handles configuration and addon dependencies. 

Versions prior to this have been minor changes under the hood of the FBW installer and these changes notes represent all changes from 3.4.0 until now.

See full **Changelog** below.

[Download Installer](https://api.flybywiresim.com/installer)

**Installer Release Notes**

This release introduces only minor changes compared to the previous version. Most users will notice small improvements in reliability and configuration handling rather than major new features.

!!! note ""
    Our installer automatically updates. Verify your version in the `Settings -> About` section of the FBW Installer.

## Changelog

- Fix addon dependencies not detected preventing installation
- Added reload-button to developer configuration
- Improved handling of checkIncompatibleAddOns
- Avoid caching of the installer configuration
- Reset-to-default button for developer configuration
- fix move people to new installer config url
