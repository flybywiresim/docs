# Installer Release v3.5.0 (Latest)

We have updated the FBW Installer to version **3.5.0**. 

See full **Changelog** below.

[Download Installer](https://flybywirecdn.com/installer/release/FlyByWire-Installer-x64.exe){.md-button}

**Installer Release Notes**

This release introduces multi-simulator support, allowing the FBW Installer to manage installations for both Microsoft Flight Simulator 2020 and Microsoft Flight Simulator 2024.

!!! note ""
    Our installer automatically updates. Verify your version in the `Settings -> About` section of the FBW Installer.

For more information on how this feature works please visit our Installer Documentation.
