## Headline Features

### SFCC Improvements

- Implement of SAP and FAP subsystems.
- More complete electrical simulation.
- Slat baulk and alpha lock functions.

### Secondary Flight Plan

- Full support for the secondary flight plan in the FMS and ND.

### MSFS EFB Flight Plan Sync

- Flight plans can be sent to or requested from the FMS in the MSFS EFB.

### New TAWS System Implementation

- New GPWS simulation with more accurate logic for all of the standard GPWS modes.

### FMS Wind Prediction Model

- Full integration of wind into the FMS predictions.
- Improved accuracy for the MCDU wind pages in the FMS.
- Added estimated takeoff time function.

### FS2024 Flight Model Improvements

- Reworked flight model accounting for FS2020/2024 differences and general improvement.

### FWS Warnings and Logic Improvements

- Improved logic accuracy for many warnings, memos, and outputs for other systems.
- Added 17 new warnings.

### FAA/LIDO Charts and Cold Temperature Calculator

- Added FS2024 FAA and LIDO charts to the EFB.
- Added a cold temperature altitude correction calculator to the EFB.

## Cockpit API Changelog

This changelog covers simulator-facing interfaces used by home cockpits, hardware integrations, and external tools.
Input Events are the stable cockpit API and should be preferred over Local Variables wherever an Input Event is
available.

### Breaking Changes

#### A32NX Removed Local Variables

The following Local Variables are no longer produced in 2024.1. Reading them may return an unset or stale value.

| Removed Local Variable | Migration |
| --- | --- |
| `L:A32NX_FWC_TOMEMO` | No public replacement is available. Do not use this variable to determine whether the takeoff memo is displayed. |
| `L:A32NX_FWC_LDGMEMO` | No public replacement is available. Do not use this variable to determine whether the landing memo is displayed. |
| `L:A32NX_FM_VNAV_TRIGGER_STEP_DELETED` | This was an internal one-shot FMS trigger and has no public replacement. |
| `L:A32NX_GPWS_GROUND_STATE` | No exact public replacement is available. Use `A:SIM ON GROUND` or the documented LGCIU outputs only when physical ground state, rather than GPWS mode, is sufficient. |
| `L:A32NX_GPWS_APPROACH_STATE` | No public replacement is available. Do not infer GPWS approach/takeoff mode from the last value of this variable. |

The GPWS removals accompany the replacement of the legacy JavaScript GPWS with the simulated GPWC. Integrations that
monitor GPWS warnings or callouts should expect trigger and timing differences even where the remaining output variable
names are unchanged.

#### A32NX NAV/LOGO Light Switch

The NAV/LOGO light switch now has three positions: OFF, system 1, and system 2. `A:LIGHT NAV` and `A:LIGHT LOGO` remain
Boolean aggregate states and cannot distinguish system 1 from system 2.

To read or command the exact switch position, migrate to `B:A32NX_OVH_LIGHTS_NAV_LOGO_SW` and its bindings:

- `B:A32NX_OVH_LIGHTS_NAV_LOGO_SW_Set` with an argument of `0`, `1`, or `2`;
- `B:A32NX_OVH_LIGHTS_NAV_LOGO_SW_Inc` and `B:A32NX_OVH_LIGHTS_NAV_LOGO_SW_Dec`;
- `B:A32NX_OVH_LIGHTS_NAV_LOGO_SW_OFF`, `B:A32NX_OVH_LIGHTS_NAV_LOGO_SW_SYS_1`, and
  `B:A32NX_OVH_LIGHTS_NAV_LOGO_SW_SYS_2`.

The corresponding state Local Variable is `L:A32NX_LIGHTS_NAV_LOGO`, where `0` is OFF, `1` is system 1, and `2` is
system 2. Legacy NAV and LOGO light key events remain supported, but cannot select both systems independently through a
Boolean state.

### Compatibility additions

No intercepted standard key events were removed. `PARKING_BRAKES_ON` and `PARKING_BRAKES_OFF` are newly handled on both
aircraft and explicitly set the parking-brake lever on or off. Existing `PARKING_BRAKES` toggle and `PARKING_BRAKE_SET`
handling remains available.

### Deprecations

The legacy FCU, FMA, autopilot, and autothrust Local Variables listed in the Deprecated section of
`fbw-a32nx/docs/a320-simvars.md` remain available for compatibility in 2024.1, but are not stable cockpit API. New
integrations should not introduce dependencies on them.
