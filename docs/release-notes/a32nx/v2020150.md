# FS2020 A32NX Stable Release v2020.15.0

<!-- ![a32nx_release_0140.png](../assets/a32nx_release_0140.png) -->

This Stable release brings a significant systems improvement to the A32NX.

**Highlights in this release include:**

- [x] SFCC Improvements
- [x] Secondary Flight Plan
- [x] New TAWS System Implementation
- [x] FMS Wind Prediction Model
- [x] FWS Warnings and Logic Improvements
- [x] General polish and improvements across the EFB (flyPadOS), Systems, and Instruments

For a full release changelog - [see here](#changelog)

## Headline Features

### SFCC Improvements

- Implement of SAP and FAP subsystems.
- More complete electrical simulation.
- Slat baulk and alpha lock functions.

### Secondary Flight Plan

- Full support for secondary flightplan in the FMS and ND.

### New TAWS System Implementation

- New GPWS simulation with more accurate logic for all of the standard GPWS modes.

### FMS Wind Prediction Model

- Full integration of wind into the FMS predictions.
- Improved accuracy for the MCDU wind pages in the FMS.
- Added estimated takeoff time function.

### FWS Warnings and Logic Improvements

- Improved logic accuracy for many warnings, memos, and outputs for other systems.
- Added 17 new warnings.
