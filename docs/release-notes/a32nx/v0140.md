## Headline Features

### IRS / ADIRU Improvements
- Added excess-motion and latitude limit (> 82° N/S) faults.
- Updated to realistic enhanced IRS align times plus quick re-align.
- New IRS-related faults and flashing EWD text via the FWC.

### Altimetry & Baro Reference Improvements
- ADR now uses accurate altimetry computations.
- Independent baro corrections per side with an extended 745–1100 hPa range.
- New baro ref / altitude discrepancy alerts and **CHECK ALT** message on the PFD.

### FMS & Navigation Improvements
- Improved leg geometry (CR/FC), DME positions, and pseudo-waypoint handling.
- Better fuel predictions aligned with the engine model.
- Added approach via auto-selection, refined GA PERF speeds, and fixed rare airway load issues.

### ECAM Control Panel & FWS / ECAM Warnings
- Fully simulated ECAM Control Panel (ECP) for the A32NX.
- Improved PRED W/S OFF, altitude alerting, AUTO BRK flashing, BAT 1(2) OFF and AP OFF logic.
- Active warnings are no longer cleared when entering inhibited phases.

### EFIS, PFD & EIS Polish
- Fixed malformed “W” glyph and ND range/mode font issues.
- Improved approach message placement and TAS/GS/Wind source handling.
- New PFD indications linked to updated FWS/altimetry logic.

### EFB, ATSU & Ground Services
- Fixed EFB settings overflow and clarified “US Units” pin behaviour.
- Split jetway and stairs buttons for correct jetway connection in MSFS 2024.
- Improved Hoppie ACARS reliability and added GSX external-power synchronisation.

### Cockpit Interaction, Model & General Behaviour
- Enabled mouse-drag for knobs in lock mode and fixed snapping behaviour.
- Smoothed speedbrake handle animation and corrected FADEC GND PWR PB logic.
- Fixed A32NX lighting issues and reduced long freezes in some MSFS 2024 scenarios.
