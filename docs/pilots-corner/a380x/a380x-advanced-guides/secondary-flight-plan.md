This advanced guide introduces the operation of the secondary flight plan index and its functionality.

## What Are Secondary Flight Plans?

Secondary flight plans can be used as a backup to the active flight plan. The A380 can store up to 3 secondary flight plans which are independant from each other and can be changed to the active flight plan at any time.

## Secondary Flight Plan Index Overview

The secondary flight plan index page can be found by clicking on the `SEC INDEX` menu and selecting the relevant secondary index.
